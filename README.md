# Bankademin Saldo app - React Project


## 📌 Overview

The Bankademin Saldo app is an interactive web application built using React. The goal of the project is to simulate a virtual bank account inside an bank application that the user must take care of by managing its valuta, income, and expenses.


## 🎯 What It Is

This project is an application that:

Simulates an bank account 

Lets users interact with the account balance through different actions like paying bills, register of income and changing the valuta in form of forums

Has a component for latest transactions that can led one to a page with all the transactions in chronological order

Has a component for bills categorized by month and categories. Using recharts, I used the bar graph tool

Fetches data from an API to enhance the app (rates for valuta)

Tracks the current balance of the account 

Provides feedback and error handling that the user can see


## 🛠️ Technologies Used

HTML – for structuring the web page  

CSS – for styling and layout  

JavaScript – for functionality and interactivity  

API – for dynamic data (using `fetch()`)

React - for user friend functionality

Route - for easy routes

recharts - for bar graph

Claude - for AI companion 


## 🚀 Requirements Met

- Minst 5 komponenter med tydligt ansvar, rimlig mappstruktur
- Routing mellan minst två vyer
- State delas mellan minst två komponenter
- Minst ett API-anrop med loading- och felhantering
- Minst ett formulär med validering
- Data lagras mellan sidladdningar
- Ren, namngiven och committad kod
  
(VG)
- Utökad felhantering: tydliga tomma-tillstånd (t.ex. "inga resultat hittades"), samt hantering av nätverksfel
- Genomtänkt komponentarkitektur: återanvändbara komponenter, egna hooks för delad logik, tydlig separation mellan presentation och datahämtning
- Responsiv design: gränssnittet fungerar och ser bra ut även på mobil skärmstorlek
- Utökad funktionalitet utöver de gemensamma kraven, motiverad och relevant för idén (sortering)
- Tydlig och väl underhållen commit-historik med beskrivande commit-meddelanden genom hela arbetet, inte bara i slutet
- Komplett inlämning enligt ovan
